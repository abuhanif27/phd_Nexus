# Project structure

```
phd_Nexus/
├── backend/          # Django REST API, apps (users, patients, doctors, records, scheduling, ai, etc.)
├── frontend/         # Next.js + React (app/, components/, features/)
├── docs/
├── launch.sh, start-all.sh, stop-all.sh
└── SETUP.md, README.md
```

**Run:** `./start-all.sh` → Frontend :3000, Backend :8000. See SETUP.md.
