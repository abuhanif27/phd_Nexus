╔══════════════════════════════════════════════════════════════════╗
║                    TROUBLESHOOTING                               ║
╚══════════════════════════════════════════════════════════════════╝

❌ Error: "Failed to analyze symptoms"
   → You're not logged in
   → Solution: Go back to STEP 1 and login

❌ Yellow banner appears saying "Not Logged In"
   → Your session expired
   → Solution: Click the login link

❌ Nothing happens when clicking analyze
   → Check browser console (F12 → Console tab)
   → Look for red error messages
   → Contact support with screenshot

❌ Backend error
   → Make sure backend is running:
     cd backend && python3 manage.py runserver
   → Check: http://localhost:8000

╔══════════════════════════════════════════════════════════════════╗
║                    QUICK TEST                                    ║
╚══════════════════════════════════════════════════════════════════╝

Test if you're logged in:
1. Press F12 (open developer tools)
2. Go to Console tab
3. Type: localStorage.getItem('accessToken')
4. Press Enter

Result:
• If shows a long string → ✅ You're logged in
• If shows "null"       → ❌ You need to login
